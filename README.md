# 철기 소녀 한글패치 3.1.3080

Steam Cavalry Girls 3.1.3080 / 빌드 26425339 / Windows x64용 비공식 한국어 패치입니다. 일본어 언어 슬롯을 한국어로 대체합니다. Codex와 Claude Code를 이용해 제작했습니다.

이번 빌드에서 신규 UI 문구 1건을 번역했습니다. 기존 텍스트의 키 변경·삭제·원문 변경은 0건이며, 내용이 같은 기존 번역과 검수는 새 위치로 이월했습니다. 이 ZIP은 지정된 게임 빌드에만 설치하세요.

[시험 릴리스](https://github.com/yoodong724/CavalryGirls-ko/releases/tag/3.1.3080-build26425339)에서 `CavalryGirls-Korean-3.1.3080-build26425339.zip`과 같은 이름의 `.zip.sha256`을 받으세요. GitHub가 자동 생성한 Source code ZIP은 설치 파일이 아닙니다.

격리 사본에서 2560×1440 한국어 타이틀, 메뉴와 빈 불러오기 화면을 확인했습니다. 신규 UI 문구 표시는 확인하지 않았습니다. 저장된 게임 불러오기, 이벤트 대사·선택지와 전투 HUD도 미확인입니다.

Enc/Cloth는 번역 범위에서 제외되며 내용이 확인되지 않았습니다. 전체 콘텐츠, DLC 심층 분기, 드문 UI 상태와 공중 투하 포드 안내 폭도 미확인입니다. 게임 원본, 세이브, 비공개 실행 화면과 로그는 배포하지 않습니다.
