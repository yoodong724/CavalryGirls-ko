# r15 확인 범위

대상: 게임 3.1.3050 / Steam 빌드 26175764 / 내부 r15. 신규 제조사명 4건을 번역했고 기존 키 변경은 0건입니다. 전체 10,353개 텍스트의 자동 QA와 L1·L2 검수, 실제 원본 사본에 대한 삽입 사전 검사, 독립 빌드 2회의 출력 해시 일치와 차분 복원을 확인했습니다.

이번 빌드에서는 게임을 실행하지 않았습니다. 한글 타이틀·메뉴, 이벤트 대사·선택지, 전투 HUD, 아이템 제조사 표시(신규 제조사명 포함), 저장·불러오기는 모두 미확인이며 사용자 확인 대상입니다. 자동 검사 통과를 게임 화면 표시 성공으로 확대하지 않습니다.

Enc/Cloth 암호화 내용은 제외되고 의미가 미확인입니다. 공중 투하 포드 안내 폭, 재주조·복제·자동 조립 등 드문 UI 상태, DLC 심층 대사와 분기, 모든 게임 효과 계산도 미확인입니다. 이전 빌드에서 관찰된 분석 SDK HTTP 오류와 종료 음향 콜백 예외의 원인도 확인되지 않았습니다.

문제를 제보할 때 게임 버전·빌드, 화면과 진입 순서를 적어 주세요. 세이브나 개인 로그는 공개 댓글에 올리지 마세요. 게임 업데이트 후에는 이전 빌드 백업을 복원하지 말고 Steam 무결성 검사로 새 원본을 준비하세요.
