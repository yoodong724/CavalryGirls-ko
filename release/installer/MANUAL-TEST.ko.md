# 실기 확인표

프로필 버전 3.0.2950을 기준으로 다음을 확인하세요.

- 타이틀 이미지와 한국어 글꼴이 정상 표시되는지 확인.
- 2560×1440에서 보관함·상점·상세창 본문·업그레이드 목록의 잘림과 행간을 확인.
- 재주조·복제의 빈 슬롯 초기 안내 및 아이템을 넣은 뒤 동적 표시를 확인.
- 자동 조립·자동 선물·제작 검색과 필터·전투 HUD의 새 문구를 확인.
- 접근 가능한 새 DLC 대사·장비·지도 설명의 줄바꿈을 확인. 미출시 부분은 실제 접근 후 별도 확인.
- 저장/불러오기와 복원 스크립트를 확인.

# 3.0.2950 추가 실기 확인

이 파일은 자동 검사 결과가 아닌 사람의 실행 확인 목록입니다. 현재 게임 실행 검증은 하지 않았습니다.

- 3.0.2950 / Steam 빌드 25429822의 깨끗한 사본에 후보를 설치하고 일본어 언어 슬롯에서 한국어를 확인합니다.
- 타이틀과 한글 글꼴, 자동 조립·선물·제작 검색/필터·전투 HUD를 확인합니다. 보관함/상점/상세창은 2560×1440에서 잘림·행간·줄바꿈을 봅니다.
- 협동 메인 기지의 공중 투하 포드 안내는 실행 중 부모 레이아웃이 폭을 정합니다. 정적 폭 통과 판정은 하지 않았으며 실제 표시 후 줄바꿈·자동 크기·잘림을 확인합니다.
- 크레디트는 게임에 포함된 별도 글꼴로 한국어와 일본어 성우명을 함께 표시하도록 연결했습니다. 특히 `早瀬水音`의 `瀬`, 글자 크기와 줄바꿈을 확인합니다.
- 새 고정 UI의 투하 포드/도시 방어 안내, 호감도, 록온 안내 및 성우 크레디트도 확인합니다.
- DLC3 도입부 세 장면은 올바른 대사가 마지막 화면에 남는지 봅니다. 원본에 유효 키와 무효 키를 가진 Translater가 함께 있어 실제 콜백 순서는 미확인입니다.
- DLC3StartPlot3는 원본 CSV의 누락된 일본어 칸만 추가했습니다. 실제 파서와 화면에서 전체 한국어 문장이 나오는지 확인해야 합니다.
- 미출시 DLC 사전 탑재 문구도 번역 대상에 포함했습니다. 접근할 수 없는 장면은 해금 뒤 확인합니다.
- 별도 시험 세이브로 저장·불러오기, 대사·선택지·변수 치환을 확인합니다. 원래 세이브는 보존합니다.

이 버전은 사용자의 요청으로 공개하는 테스트 후보입니다. 공개 여부와 위 실기 확인 완료 여부는 별개입니다.
