# 수동 확인표

r05 상세창 간격과 이전 r04 수정은 사용자가 적합하다고 확인했습니다. 아래 목록 전체가 검증됐다는 뜻은 아닙니다. 새로운 버전이나 재현 문제를 확인할 때 사용하세요.

- 한국어 선택 후 타이틀·메뉴·설정·불러오기의 한글과 폰트 깨짐·잘림.
- 2560×1440에서 긴 무기 상세창의 제목·본문·수치·하단 목록이 화면 안에 들어오고 줄이 겹치지 않는지.
- 상점 상세창의 업그레이드·개조 모델 안내, 재주조·복제 화면의 빈 슬롯 및 아이템 입력 후 수치·문구 갱신.
- 전투 HUD의 한글과 H/M 키 안내, HUD 상태 전환 후 표시.
- 도입부·튜토리얼·분기 대사의 순서·화자·선택지·진행.
- 아이템·기체·보스 등의 이름, 수치·태그·변수와 긴 문장 표시.
- 저장 후 종료·재실행·불러오기와 진행 상태 유지.
- 게임 종료 후 `restore.cmd`로 복원하고 정상 실행.

확인하지 못한 분기·해상도·세이브 상태는 미검증으로 남기세요. 실패 시 화면, 버전, 재현 경로와 로그를 기록합니다.
