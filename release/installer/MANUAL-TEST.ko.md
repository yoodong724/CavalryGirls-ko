# r16 확인 범위

대상: 게임 3.1.3080 / Steam 빌드 26425339 / 내부 r16. 신규 UI 문구 1건을 번역하고 자동 QA와 독립 L1 검수를 수행했습니다. 기존 키 변경은 0건이며, 내용이 같은 기존 10,353건의 승인을 이월했습니다. 신규 UI 문구는 L2 대상에서 제외됩니다.

격리 사본에서 2560×1440 한국어 타이틀, 메뉴와 빈 불러오기 화면을 확인했습니다. 저장 파일이 없어 실제 불러오기는 확인하지 못했습니다. 신규 UI 문구 표시는 확인하지 않았습니다. 이벤트 대사·선택지, 전투 HUD와 게임플레이도 미확인입니다.

Enc/Cloth 암호화 내용은 제외되고 의미가 미확인입니다. 공중 투하 포드 안내 폭, 재주조·복제·자동 조립 등 드문 UI 상태, DLC 심층 대사와 분기, 모든 게임 효과 계산도 미확인입니다. 이전 빌드에서 관찰된 분석 SDK HTTP 오류와 종료 음향 콜백 예외의 원인도 확인되지 않았습니다.

문제를 제보할 때 게임 버전·빌드, 화면과 진입 순서를 적어 주세요. 세이브나 개인 로그는 공개 댓글에 올리지 마세요. 게임 업데이트 후에는 이전 빌드 백업을 복원하지 말고 Steam 무결성 검사로 새 원본을 준비하세요.

방어 설정의 한 고정 UI 문구는 이전 빌드와의 신규 여부가 확인되지 않아 패치하지 않았습니다. 해당 화면 표시도 미확인입니다.
