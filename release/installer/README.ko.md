# Cavalry Girls 한국어 패치 3.1.3048

대상: Steam 빌드 26154816 / Windows x64 / 내부 패치 r14. Codex를 이용해 제작했습니다. 다른 게임 빌드에는 설치하지 마세요.

1. 게임을 종료하고 Steam 파일 무결성 검사로 해당 빌드의 깨끗한 원본을 준비하세요.
2. 기존 `.cavalry-girls-ko-backup`은 다른 이름으로 보관하세요. 다른 빌드의 백업을 섞거나 복원하지 마세요.
3. ZIP을 게임 폴더 안에 풀어 `CavalryGirls.exe`와 `CavalryGirls-Korean-r14` 폴더가 같은 위치에 있게 하세요.
4. 패치 폴더의 `install.cmd`를 실행하세요. 게임 언어에서 일본어 슬롯을 선택하면 한국어가 표시됩니다.

원복은 게임을 종료하고 같은 폴더의 `restore.cmd`를 실행하세요. 게임 업데이트 뒤에는 이전 백업을 복원하지 말고 Steam 무결성 검사로 새 원본을 준비하세요. 설치 전 중요한 세이브는 별도 보관하세요.

격리 사본에서 타이틀·메뉴·저장 불러오기·아이템·대원 관리 화면과 저장 동작을 확인했습니다. 사용자의 테스트 중단 지시에 따라 나머지 화면·기능은 직접 확인 대상으로 남겼습니다. Enc/Cloth는 제외되며 전체 DLC, 드문 UI 상태와 모든 분기를 검증한 버전은 아닙니다. [확인 범위](MANUAL-TEST.ko.md)를 참고하세요.
