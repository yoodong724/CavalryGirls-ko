# Cavalry Girls 한국어 패치 3.1.3032

대상: Steam 빌드 26134654 / Windows x64 / 내부 패치 r13. Codex를 이용해 제작했습니다. 다른 게임 빌드에는 설치하지 마세요.

1. 게임을 종료하고 Steam 파일 무결성 검사로 해당 빌드의 깨끗한 원본을 준비하세요.
2. 기존 `.cavalry-girls-ko-backup`은 다른 이름으로 보관하세요. 다른 게임 빌드의 백업을 섞거나 복원하지 마세요.
3. ZIP을 게임 폴더 안에 풀어 `CavalryGirls.exe`와 `CavalryGirls-Korean-r13` 폴더가 같은 위치에 있게 하세요.
4. 패치 폴더의 `install.cmd`를 실행하세요. 게임 언어에서는 일본어 슬롯을 선택하면 한국어가 표시됩니다.

원복은 게임을 종료하고 같은 폴더의 `restore.cmd`를 실행하세요. 게임 업데이트 뒤에는 이전 백업을 복원하지 말고 Steam 무결성 검사로 새 원본을 준비하세요. 설치 전 중요한 세이브는 별도 보관하세요.

격리 사본에서 설치·재설치·원복과 기본 플레이, 저장 후 불러오기를 시험했습니다. 전체 DLC·드문 UI 상태·모든 분기와 효과 계산까지 검증한 버전은 아닙니다. 공중 투하 포드 안내 폭, 재주조·복제·자동 조립 등의 세부 화면은 미확인입니다. 종료 음향 콜백 예외와 분석 SDK 통신 오류도 관찰했으며 원인은 미확인입니다. [실기 확인표](MANUAL-TEST.ko.md)에 실제 확인 범위와 남은 항목을 적었습니다.
