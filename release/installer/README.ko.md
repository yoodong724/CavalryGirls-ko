# Cavalry Girls 한국어 패치 3.1.3084

대상: Steam 빌드 26426685 / Windows x64 / 내부 패치 r17. Codex와 Claude Code를 이용해 제작했습니다. 다른 게임 빌드에는 설치하지 마세요.

1. 게임을 종료하고 Steam 파일 무결성 검사로 해당 빌드의 깨끗한 원본을 준비하세요.
2. 기존 `.cavalry-girls-ko-backup`은 다른 이름으로 보관하세요. 다른 빌드의 백업을 복원하지 마세요.
3. ZIP을 게임 폴더 안에 풀어 `CavalryGirls.exe`와 `CavalryGirls-Korean-r17` 폴더가 같은 위치에 있게 하세요.
4. 패치 폴더의 `install.cmd`를 실행하고, 게임에서 일본어 언어 슬롯을 선택하세요.

원복은 게임을 종료하고 `restore.cmd`를 실행하세요. 게임 업데이트 뒤에는 이전 백업을 복원하지 말고 Steam 무결성 검사로 새 원본을 준비하세요. 중요한 세이브는 별도로 보관하세요.

게임 실행 화면은 확인하지 않았습니다. 저장된 게임 불러오기, 대사·선택지, 전투 HUD, 드문 UI 상태와 DLC 전체는 미확인입니다. Enc/Cloth는 번역 범위에서 제외됩니다. [확인 범위](MANUAL-TEST.ko.md)를 참고하세요.
