# 철기 소녀 한글패치 r05

지원 버전: Steam Cavalry Girls 2.6.2859 / 빌드 24639430 / Windows x64.

총 8,778개 번역 레코드, 한국어 폰트와 타이틀, 고정 UI 및 상세창 간격 수정을 포함합니다. 한국어는 일본어 슬롯을 대체합니다. r05 상세창 간격과 앞선 r04 수정은 사용자 확인을 받았습니다. 전체 분기·세이브·해상도의 전수 검증을 뜻하지는 않습니다.

## 설치

1. 기존 한글패치가 있다면 게임을 종료하고 기존 패치 폴더의 `restore.cmd`로 원본을 복원합니다. 성공한 뒤 게임 폴더의 `.cavalry-girls-ko-backup`을 `.cavalry-girls-ko-backup-r04`처럼 겹치지 않는 이름으로 바꿔 보관하세요.
2. Steam에서 게임의 **관리 → 로컬 파일 탐색**으로 게임 폴더를 엽니다.
3. ZIP 안의 `CavalryGirls-Korean-r05` 폴더를 게임 폴더 안에 풉니다. 배치는 `Cavalry Girls\CavalryGirls-Korean-r05\install.cmd`가 됩니다. ZIP 내부에서 실행하지 마세요.
4. 게임을 종료한 상태에서 `install.cmd`를 실행합니다. 설치기는 패치 폴더 바로 위를 게임 폴더로 사용합니다.
5. 완료 후 Steam에서 게임을 실행하고 언어를 **한국어**로 선택합니다.

Python·WSL·별도 xdelta 설치는 필요하지 않습니다. 게임 드라이브에 약 10GB의 여유 공간을 권장합니다. 원본 버전이나 해시가 다르면 설치가 중단됩니다. 설치기는 다른 버전의 백업을 덮어쓰지 않습니다.

## 복원

게임 종료 후 설치에 사용한 패치 폴더의 `restore.cmd`를 실행하세요. 원본 백업은 게임 폴더의 `.cavalry-girls-ko-backup`에 있습니다. 복원이 필요한 동안 패치 폴더와 백업을 함께 보관하세요. 게임 업데이트로 파일이 바뀌면 해당 버전에 맞는 새 패치가 필요할 수 있습니다.

패치는 `CavalryGirls_Data/resources.assets`와 `resources.assets.resS` 두 파일을 교체합니다. 두 결과를 먼저 생성·검증하고 원본을 백업합니다. 교체 실패 시 복구를 시도합니다. 세이브와 설정 파일은 수정하지 않습니다.

`VCRUNTIME140.dll` 오류가 발생하면 Microsoft Visual C++ x64 런타임을 설치한 뒤 다시 실행하세요. 권한 오류가 발생하면 게임 폴더에 쓸 수 있는 계정에서 실행하세요.

## 범위와 문제 제보

해독하지 못한 Enc/ArtBook, 타이틀 외 이미지 속 문자, 최초 진입의 중국어 로고는 범위 밖입니다. 일부 고유 표기와 크레딧은 의도적으로 유지했습니다.

문제가 발생하면 게임 버전, 화면, 진행 위치·선택지, 해당 문구와 Player.log를 기록하세요. 진행 불가·충돌·세이브 문제가 있으면 게임을 종료하고 복원한 뒤 제보하세요. 추가 확인 항목은 `MANUAL-TEST.ko.md`에 있습니다.

이 ZIP의 public1은 r05와 같은 설치 코드와 게임 차분을 사용하며, 배포 안내와 메타데이터만 갱신한 판본입니다.
